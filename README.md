## Core Patterns

- **Fact Vs Judgment Classifier**: Fact vs Judgment Separation: label verifiable data points as Facts and trade-off opinions as Judgments to prevent dogma.
- **Practical Application**: Architecture trade-off discussions, avoiding dogmatic opinions.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
